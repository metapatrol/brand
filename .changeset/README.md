# Changesets

Every change to a published package comes with a changeset: `npm run changeset`,
pick the packages and the bump, write one line for the changelog.

Bump rules for this repository:

- **major**: a token is renamed or removed, a colour role changes meaning,
  the mark's geometry changes
- **minor**: new tokens, components, assets or CLI commands
- **patch**: value tweaks that keep every contrast rule, fixes
