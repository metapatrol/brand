# @metapatrol/brand

The metapatrol brand assets, generated by `@metapatrol/brand-kit`.

| directory | contents |
|---|---|
| `mark/` | the mark: `metapatrol-mark-*` (48 px and larger), `-small-*` (20–40 px), `-favicon-*` (16 px); each in `dark`, `light`, `mono-white`, `mono-black`; SVG and PNG |
| `wordmark/` | the wordmark as outlines |
| `lockup/` | horizontal, stacked and with descriptor |
| `app/` | app icon, avatars (`light` for GitHub and Forgejo), `favicon.svg` (follows the colour scheme), `favicon.ico` |
| `construction/` | the construction on the lattice, clear space |

`dark` files are for dark backgrounds (steel structure), `light` files for light
ones (graphite). Keep a clear space of a quarter of the mark's height around it.

```html
<link rel="icon" href="node_modules/@metapatrol/brand/app/favicon.svg" type="image/svg+xml">
```

Without a package: every release's files are in its GitHub release as
`metapatrol-brand-X.Y.Z.zip`. Inside the metapatrol network they are also served
at `https://brand.metapatrol.local/assets/<version>/…` and `/assets/latest/…`
(behind the forge's login, not reachable from outside).
