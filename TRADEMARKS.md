# metapatrol name and marks

The code in this repository — the design tokens, the styles, the generator and
the components — is licensed under the Apache License 2.0 (`LICENSE`). As
section 6 of that licence states, it does **not** grant permission to use the
metapatrol name, the metapatrol mark or the metapatrol wordmark ("the marks").

The asset files that show the marks are not under the Apache License at all;
see `LICENSE.md` in `@metapatrol/brand` (`packages/brand/`). This document
says how they may be used.

## what you may do without asking

- Use the marks unchanged to refer to metapatrol or to a metapatrol project,
  for example in articles, talks, documentation or a list of tools you use.
- Use `@metapatrol/*` packages in your own software. Styles and tokens are
  yours to use under the code licence.
- Keep the marks in a fork while you refer to the upstream project.

## what needs permission

- Using the marks for a product, service, organisation or project that is not
  a metapatrol project, including forks distributed under their own name.
- Changing the marks: other colours, other proportions, effects, combining them
  with another logo, or using parts of the mark as a new logo.
- Using the marks in a way that suggests metapatrol endorses something it does not.

## how to use them

Use the files from `@metapatrol/brand`, keep the clear space and colour rules
from the brand identity document, and write the name in lowercase: `metapatrol`.
